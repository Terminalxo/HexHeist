# Changelog

## 1.0.0 - 2026-08-12

Initial HexHeist beta source release.

### Added

- PySide6 cross-platform desktop UI
- dark/light/system themes
- runtime AVRDUDE discovery
- runtime part/programmer catalogs
- quick flash and verify
- generic memory operation queue
- fuse/lock reads and immediate writes
- chip erase and signature read
- AVRDUDE terminal mode
- advanced options and custom arguments
- live console and log export
- recent firmware files
- command history
- persistent settings
- core unit tests and project documentation
