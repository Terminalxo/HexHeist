# HexHeist Roadmap

## 1.0 — Core desktop programmer

- modern cross-platform UI
- runtime part/programmer catalogs
- memory operations
- fuse/lock operations
- terminal
- advanced flags
- logging and settings

## 1.1 — Profiles and device intelligence

- named programming profiles
- JSON import/export
- programmer-to-part compatibility filtering
- richer device metadata
- optional connected-device signature helper

## 1.2 — Fuse experience

- semantic fuse visualization where authoritative metadata is available
- before/after fuse diff
- safer warnings for programming-interface/clock-related fuse changes

## 1.3 — Distribution

- macOS universal package and signing/notarization pipeline
- Windows installer/signing pipeline
- Linux AppImage/Flatpak evaluation
- release checksum publication

## Long term

- hardware-in-loop regression suite
- optional libavrdude backend if it offers a stable cross-platform deployment advantage
- plugin hooks for programmer-specific UX without hard-coding vendor behavior into the core
